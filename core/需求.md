# 文字游戏制作器 — 需求文档（最终确认版）

## 一、项目概述

一个**自用的可视化互动叙事编辑器**。在电脑上编辑带分支的剧情，导出为单个 HTML 文件，在手机浏览器中游玩。

---

## 二、使用场景

| 环节 | 平台 | 说明 |
|------|------|------|
| 编辑剧情 | 电脑（浏览器） | 创建节点、写文本、设分支、配变量 |
| 试玩测试 | 电脑（浏览器） | 编辑器内预览，验证分支走向 |
| 游玩 | 手机浏览器 | 打开导出的 HTML 文件即可玩 |

---

## 三、功能需求

### 1. 剧情节点编辑

- 新建、删除、复制、重命名节点
- 每个节点包含：
  - 标题（编辑器内管理用，玩家不可见）
  - 正文文本（纯文本，支持换行）
  - 选项列表（0 个或多个）
- 无选项的节点视为结局节点

### 2. 分支系统

- 每个选项包含：
  - 选项文字（玩家可见）
  - 跳转目标节点
  - 显示条件（可选，基于变量）
  - 执行效果（可选，修改变量）
- 分支数量不限，可自由增删
- 多个分支可指向同一节点（剧情收束）
- 支持无条件自动跳转（不显示选项，直接进入下一节点）

### 3. 变量系统

- 全局变量表，每个变量包含：
  - 名称
  - 类型（数字 / 布尔）
  - 初始值
- 选项可执行变量操作：加减、赋值
- 选项可设置显示条件（基于变量判断）
- **条件表达式支持复合条件**（如 `好感度 >= 5 且 hasKey == true`）
- 支持条件跳转：节点根据变量自动走向不同后续

### 4. 视图

- **列表视图**：左侧节点列表，右侧编辑当前节点
- **节点图视图**：可视化展示分支结构（第一期就要）
- 两种视图可切换，数据实时同步

### 5. 测试预览

- 编辑器内一键试玩
- 可从任意节点开始
- 显示当前变量值（调试用）
- 支持回溯上一步

### 6. 存档与导出

- 项目保存为本地文件（JSON）
- 导出为单个 HTML 文件，手机浏览器直接打开即可游玩
- 导出内容包含：剧情数据 + 运行时引擎 + 阅读界面

---

## 四、非功能需求

| 项目 | 要求 |
|------|------|
| 用户 | 仅自己使用，无需账号、协作、权限 |
| 文本量级 | 短篇 |
| 多媒体 | 不需要，纯文字 |
| 手机端 | 浏览器打开即玩，无需安装 |
| 手机阅读界面 | **浅色主题**，适配小屏，操作简单 |
| 编辑器形态 | 纯网页版，浏览器打开即用 |

---

## 五、技术方案

| 部分 | 技术 |
|------|------|
| 编辑器 | HTML + CSS + JavaScript |
| 运行时引擎 | JavaScript（与编辑器共用逻辑） |
| 数据格式 | JSON |
| 导出物 | 单个 HTML 文件（内嵌 JSON + 引擎 + 界面） |
| 本地存储 | 浏览器 LocalStorage / 手动下载 JSON |

---

## 六、边界说明（不做的事）

- 不做多人协作、云端存储、版本历史
- 不做富文本、图片、音效、视频
- 不做角色立绘、物品图鉴、结局收集等扩展系统
- 不做账号、登录、权限
