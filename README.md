# 互动叙事编辑器 (Interactive Narrative Editor)

一个零外部依赖（Zero-Dependency）、完全基于浏览器的可视化互动叙事创作与阅读环境。无需构建、无需安装 npm 包、无需后端服务，双击 `editor/index.html` 即可在本地离线运行。

---

## 特性亮点

1. **零依赖与完全离线**：
   - 纯前端实现，所有样式与脚本均内联或相对路径引用。
   - 通过将运行时引擎包装为转义字符串常量（`core/engine-source.js`），支持在 `file://` 离线协议下自由导出独立可运行的单文件 HTML。
2. **多视图可视化创作**：
   - **列表视图**：适合快速编辑节点正文、管理分支选项、多层条件及状态变更。
   - **节点图视图**：原生 SVG + Canvas/DOM 渲染，支持拖拽排版、缩放（Zoom/Pan）、自动分层布局（BFS 拓扑分层），直观呈现叙事分支。
   - **变量管理**：支持布尔值与数值类型变量，跟踪全局引用计数，防止误删正在使用的变量。
3. **强大的逻辑表达**：
   - 支持递归组合条件（全部满足 `AND` / 任一满足 `OR`），最高支持 3 层嵌套。
   - 丰富的运算符：`==`, `!=`, `<`, `<=`, `>`, `>=`。
   - 支持选项点击后的变量效果（赋值 `set`、累加 `add`、递减 `sub`）。
   - 支持节点无选项时的**自动条件跳转（Auto-Rules）**，带循环跳转保护（上限 100 次），轻松实现分流与判定结局。
4. **实时仿真试玩与历史回溯**：
   - 侧边抽屉式试玩预览，随时从任意指定节点开始。
   - 变量变化实时高亮监控。
   - 支持任意步骤「返回上一步」（时间旅行/状态回溯），无副作用。
5. **健壮的校验体系**：
   - 实时检查悬空跳转、缺失起始节点、孤岛节点、自动跳转死循环、空标题/空选项文字、未知变量引用。
6. **单文件 HTML 导出**：
   - 一键打包生成独立的阅读器 HTML，内联精美轻量阅读界面，适配桌面端与移动端，随时分享或上传任意静态托管。

## 快速上手

### 1. 打开编辑器

直接在操作系统文件管理器中**双击 `editor/index.html`**，或在终端通过默认浏览器打开：

```powershell
Start-Process editor/index.html
```

> **提示**：无需任何本地 HTTP 服务（如 `http-server` 或 `live-server`），直接以 `file://` 协议运行即可拥有完整功能（包括自动保存与文件导出）。

### 2. 载入示例故事

1. 点击顶部工具栏的 **「导入」** 按钮。
2. 在文件选择框中选中 `samples/demo-story.json`。
3. 界面将加载包含 7 个节点、3 个变量的示例故事《深夜的灯塔》。
4. 点击顶部 **「试玩」**（或按 `Ctrl + Enter`）体验剧情分支走向三种不同结局。

> **大型范例**：`samples/今天也不想拯救世界.json` 是一部 85 节点、12 变量、8 结局的搞笑向长篇，覆盖全部编辑器特性（条件选项、复合条件组、自动跳转规则链、真假结局分流、隐藏结局分支等），可直接导入试玩；它由 `node tools/gen-comedy-sample.js` 生成，该脚本会在写文件前自动执行归一化、校验、万字统计、8 条定向走线与 3000 局随机漫步自检。

### 3. 快捷键指南

| 快捷键 | 功能 |
|---|---|
| `Ctrl + S` / `Cmd + S` | 立即保存当前项目到浏览器本地存储 |
| `Ctrl + Enter` | 开启 / 关闭实时预览抽屉 |
| `Ctrl + 1` | 切换到 **列表视图** |
| `Ctrl + 2` | 切换到 **节点图视图** |
| `Ctrl + 3` | 切换到 **变量管理** |
| `Ctrl + D` | 复制当前选中的节点（连同选项分支） |
| `Delete` | 删除当前选中节点（需确认，且需非输入框聚焦状态） |
| `Esc` | 关闭当前打开的预览抽屉 |

## 开发者与测试指南

本项目不依赖任何 npm 第三方库（`node_modules` 为空），所有测试均原生运行。

### 运行单元测试与集成测试

在项目根目录下执行：

```powershell
# 1. 运行引擎核心功能测试（47项测试：数据模型、归一化、条件逻辑、效果执行、历史回溯、校验器）
node tests/run-tests.js

# 2. 运行单文件导出物与阅读器仿真测试（18项测试：HTML结构转义、状态机推演、模拟DOM交互）
node tests/test-export.js
```

### 重新打包引擎源码

如果修改了核心引擎 `core/story-engine.js`，需要重新运行包装工具将引擎同步为导出专用的转义字面量：

```powershell
python tools/build_engine_source.py
```

## 健壮性与性能设计

1. **渲染错误隔离（error boundary）**：`app.js` 的 `renderAll()` 把侧栏、当前视图、校验面板分别包在 `safeCall()` 中。任一渲染函数抛错时，其余界面照常刷新，错误会同时写入浏览器控制台与底部状态栏（同类消息只显示一次，避免刷屏）；启动阶段失败会在主区显示可读的失败原因，而不是留下一片空白。
2. **未捕获异常可见**：`window` 上注册了 `error` 监听，任何脚本异常都会转成状态栏提示，不再出现“点了没反应却不知道原因”的情况。
3. **写入前的数据修改保护**：`Store.update()` 会 `try/catch` 包裹变更函数；一旦抛错就不写 LocalStorage、不触发重绘，只提示“这次操作未能完成”，避免把半改好的数据固化进存档。
4. **输入防抖**：侧栏搜索框停顿 180ms 后才触发全量重绘（`Util.debounce`），中文输入法逐字输入不再反复重排列表；自动保存另有 400ms 防抖。
5. **大项目渲染上限**：侧栏一次最多渲染 300 个节点（`MAX_SIDEBAR_ITEMS`），超出部分给出“请用搜索过滤”的提示，并且保证当前选中节点始终可见，避免上千节点时整表重绘卡顿。
6. **事件绑定只在挂载时执行一次**：所有交互均由 `Util.on()` 在 mount 阶段以事件委托方式绑定，重绘只替换 `innerHTML`，因此渲染异常不会破坏已绑定的事件。
